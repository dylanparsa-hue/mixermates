# MixerMates reference direction — 28 October 2026

The owner supplied four event-app images and explicitly requested implementation, without another concept-selection or approval gate. Their brief replaces the rejected design. No reference photographs are imported.

This is a code-led adaptation inside the existing application, not a replacement backend. Mode: Operate, with photography leading discovery.

First viewport: official logo, location, one short heading, search, category pills, narrow date rail, event photographs with overlaid title/date/price and a separate save control. A three-column desktop grid gives the first photograph two columns; phones show one portrait card alongside the calendar. No marketing hero delays discovery.

The signature interaction is date selection beside the photo catalogue. Search, category, city, price and period still filter stored authorized upcoming events. Map exploration remains a separate route. No fictional popularity, ratings, guests or seat numbers.

Reference mapping uses the actual supplied image order:
- Image 1: restrained dark discovery region; photo leading into a rounded light detail panel; compact title and metadata.
- Images 2 and 3: white editorial discovery, black category selection, slim vertical dates, the photograph itself as the card; admission pass artwork plus a two-column information grid and perforation.
- Image 4: charcoal dark theme, large colorful photography, quiet task surfaces and a high-contrast private QR presentation.

Tokens: light canvas #F8F8F7, paper #FFFFFF, ink #141519, secondary #646871 (darkened for readable contrast), border #E2E2E6; dark canvas #101216, surface #1D2026, elevated #292D34, text #F8F8FA, secondary #A8ABB3, border #343841. Official purple/pink artwork remains; UI violet is limited to focus, small accents and semantic selection.

Type: locally bundled Manrope, 26–28px phone page titles, up to 44px discovery heading, 19–24px section titles, 18–22px card titles. Logo artwork preserves its original typography. Fixed Oxanium roles in covered operating surfaces are overridden with Manrope.

Spacing: phone gutters 20px, 16px at 360px and below; desktop fluid 28–56px, max 1280px. Cards use 16–24px padding, work surfaces 20–28px. Photography uses 22–24px corners; task controls 12–16px; navigation/category choices use capsules.

Ticket: authentic event artwork, actual holder/tier/date/location/status, perforated paper, existing secure QR. No decorative barcode competes with admission. QR remains static, white and private; safe-share exports use unchanged server code.

Motion: no opening animation, parallax, ticker or card entrance; only restrained photo hover on precise pointers. Reduced motion removes it. Public photograph derivatives are responsive WebP files; original images and protected uploads retain their originals and access checks.

Quality bar: compare actual rendered phone/desktop screenshots with these composition promises; inspect all requested widths in both themes, preserve all domain tests and independent financial approvals. All development stays in loopback-only fictional copies. Owner visual acceptance remains separate.

Honest risk: the safe Lab strip adds height absent in the supplied consumer mockups. Existing fictional photography, profile information and operating data remain the product's own content; this is an adaptation, not a pixel copy of celebrity concert artwork. Supporting dashboards receive the shared visual system rather than a new information architecture.

# Exploratory failures and corrections

Accepted evidence is tests-final.log/e2e.log and linked JSON, not an assumption that the first attempt passed.

- **Actual application bottleneck:** pre-fix SQLite25-way checkout produced slow503 responses around48 seconds despite capacity safety. Default SQLite pool is now1; accepted25-way run yields10 holds/15 expected409 responses without infrastructure failures. Non-SQLite options are unchanged.
- **Actual response gap:** a genuine Prisma SQLite initialization error can omit errorCode; the old generic500 path did not identify temporary unavailability. Safe503 handling now covers initialization/known connection/schema/conflict failures without SQL/secret output.
- **Unsafe/stale E2E tooling:** old Playwright config auto-started default pnpm dev with0.0.0.0/default-root DB risk and obsolete public-access selectors. It now requires an owned fictional prestarted loopback server and current gates. Canonical refusal is tested. No canonical server/database was actually started by that old config during Phase10.
- **New recovery-tool defect caught:** migration tuples became lists through manifest JSON round-trip, causing populated restore comparison to fail. Normalization was fixed and the unit fixture now contains a migration row; final populated restores pass.
- **Provider harness limitation:** MySQL rejects CREATE TRIGGER via prepared statements. Failure injection now uses the owned disposable Unix-socket CLI, with matching clients; no hosted credentials. Both providers pass the actual trigger/issuance recovery test.
- **Test environment interference:** an early full regression on the load DB failed the105-reminder assertion because preserved thousands of eligible load bookings consumed the worker's100-item bounded run. No old test was weakened/skipped and no database was reset/deleted. Final348 acceptance uses a separate fresh fictional workspace; load records remain in regression for evidence.
- **Browser harness corrections:** use browser-context request cookie jar for authenticated UI, scope wrapped select controls by semantic form names, use current Find your vibe heading, and create one additional independently reviewed fictional ticket for unused rendered-QR checks. Raw credential stays in memory. A test-compiler helper was injected only in the DOM-analysis browser context to support its serialized callbacks.
- **Local dev/cache/runtime:** a restarted Turbopack preview repeatedly rebuilt; its cache was moved intact outside the workspace and accepted preview uses webpack dev. A symlink-only outage copy was served with webpack to respect package resolution. A bare standalone smoke lacked the generated Prisma runtime; accepted optimized smoke uses Next start with its installed dependencies. No portable/upload release was prepared, and the incumbent MySQL release-runtime helper was not run for deployment.
- **Validation configuration:** validating the MySQL schema with a SQLite URL correctly failed; accepted MySQL schema validation uses an explicit disposable-format loopback MySQL URL without connecting to a host.

No exploratory physical/provider/live result is recast as a pass. Private raw scratch logs are preserved; only sanitized accepted logs/counts/hashes/screenshots are included in docs.

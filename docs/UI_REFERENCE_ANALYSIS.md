# MixerMates reference analysis

Inspected 27 October 2026 in the owner's authenticated Google Chrome session through native computer-use tools. Aura was read-only. No project was saved, remixed, exported, purchased or published. No Aura assets or source code were copied into the application.

## Reference 1: CinemaVision Pro

Exact editor: https://www.aura.build/editor/f5b3fafa-dbf1-455e-ba08-6880cdd43dfb

The rendered project was titled **CinemaVision Pro Entertainment Booking Template — home**. Its strongest composition combines an image-wall cinema hero, large left-aligned film title, a tall poster beside the copy, distinct primary/secondary actions and a persistent translucent navigation bar. Below it are screening choices, a curved screen, seat grid and booking summary.

Observed at desktop, tablet 768×1024 and phone 393×852 using the editor's preview controls. The phone stacks the poster below the title/actions. Content revealed after the responsive preview changed, and the header remained visible over the page during scroll. Theater and hamburger clicks produced no visible state change in this session. These are not claimed as working seat-selection or menu animations.

Adapt: photograph plus event highlight; clear booking hierarchy; persistent navigation; readable selection and summary surfaces. Exclude: seat diagrams, cinema ratings, film imagery, theater terminology and blue/orange branding.

## Reference 2: Spartan Endurance

Exact template: https://www.aura.build/templates/endurance-race-71

The live preview opened from this page was https://endurance-race-71.aura.build/. Its strongest features are oversized condensed headlines, full-width atmospheric imagery, a capsule navigation bar, strong section spacing, contrasting moving type bands, photographic event rows and admission sections. Desktop scroll inspection showed content changing from softened/blurred to clear as sections entered view; navigation remained persistent. The repeating text band supplies a useful pacing device. Tablet and phone previews replace the full navigation with an icon menu and retain a prominent action. The event-details button produced no visible destination change in the inspected preview.

Adapt: oversized Oxanium lettering, controlled headline/image reveals, moving brand band, expansive event photography, quieter information below the hero. Exclude: running imagery, race statistics, competitive/military copy, unrelated testimonials and claims, red sports branding and sample ticket prices.

## One system

Use MixerMates' existing midnight/navy, purple/violet/pink, Manrope/Oxanium and official raster logo. The replacement world is cinematic event discovery with precise work surfaces: one photographic hero beside a configured event highlight; readable image/text event cards; a compact search and date rail; consistent navigation, forms, dialogs and status components. Booking, finance, approvals and entrance keep their existing authoritative states and actions.

This is a code-led application redesign. The owner's pinned blend is the direction contract; the references are inspiration, not approved pixel-matching comps. The Impeccable concept-seed exercise was consulted for unpinned dimensions, without replacing the owner's selection with an unrelated world.

## Observation limits

Native Chrome controls exposed click, scroll and viewport-preview controls, but no pointer-hover API. Exact source animation durations, easing curves, frame rates, hover behavior and reduced-motion implementation could not be measured. Application timings are authored adaptations, documented in UI_ANIMATION_SPEC.md. No unobserved reference interaction is presented as reproduced behavior. The local implementation's hover, pause, scroll and reduced-motion behavior is tested separately in a controlled browser.
